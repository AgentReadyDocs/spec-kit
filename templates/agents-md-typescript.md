# AGENTS.md (TypeScript) — starter template

Use this as a starting point for a new TypeScript repository, then tailor to your stack and conventions.

## CRITICAL

- MUST: Keep commands deterministic (pin Node + lockfile).
- MUST: Run `lint` and `test` before PR.
- NEVER: Commit secrets or credentials.

## Env

- Node: `>=<fill>`
- Package manager: `pnpm` (or `npm` / `yarn`)

## Commands

```bash
# install
pnpm install
# lint
pnpm lint
# test
pnpm test
```

## Notes

- If you use codegen, add an explicit `codegen` command.
- If you use formatting, add `format` and/or `format:check`.
